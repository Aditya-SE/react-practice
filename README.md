## Getting Started

Clone the repository:

```bash
git clone https://github.com/Aditya-SE/react-practice.git
```

Move into any project folder:

```bash
cd cards
```

or

```bash
cd todoList
```

or

```bash
cd lottery
```

or

```bash
cd comment section
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
